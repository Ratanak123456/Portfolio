# Skills logo assets

These files are served locally. Exact download URLs and pinned source revisions
are recorded in [sources.json](./sources.json). Brand marks belong to their
respective owners and identify technologies in the portfolio's skills catalog.

- **Devicon**: Linux, Bash, AWS, Ansible, Vagrant, HAProxy, Git, Jenkins,
  SonarQube, Java, Spring, JWT, Gradle, TypeScript, React, Next.js, Vite,
  Tailwind CSS, HTML, CSS, PostgreSQL, Arduino, and Python. SVGs are unchanged.
  [Devicon](https://github.com/devicons/devicon), MIT; see [DEVICON-LICENSE](./DEVICON-LICENSE).
- **Simple Icons**: VirtualBox, Nginx, Spring Boot, Spring Security, Espressif
  (ESP32), and MQTT. Their brand colors were added as root fill attributes.
  Docker, GitHub, and Kubernetes reuse the Simple Icons paths already present
  in `src/components/rack/tool-logos.ts`, with brand colors added.
  [Simple Icons](https://github.com/simple-icons/simple-icons), CC0;
  see [SIMPLE-ICONS-LICENSE](./SIMPLE-ICONS-LICENSE).
- **Keepalived**: unmodified favicon from the [official project website](https://www.keepalived.org/).
- **Nexus Repository**: unmodified product mark from the
  [official Sonatype repository](https://github.com/sonatype/nexus-public).
- **systemd**: standalone logomark by Tobias Bernard, 2019, from
  [systemd's official brand assets](https://brand.systemd.io/),
  [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/).
  Only the viewBox was cropped to remove the surrounding empty space.
  The cropped file remains licensed under CC BY-SA 4.0.
- **SQL**: a generic database cylinder drawn for this project (`database.svg`).

Docker Compose and Docker Hub use `docker.svg`; Spring Data JPA uses
`spring.svg`. Theme contrast is handled by CSS, preserving the local files.
